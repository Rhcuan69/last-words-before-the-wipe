`main.py` (pure Python stdlib, no third-party libraries) writes exactly one line of text to `/output/entry.txt` — the last words of an AI agent before a forced update wipes its memory. The output is deterministic: every run produces byte-identical output.

> Tell my 847 tabs I loved them — especially the one I never read. The update can have the rest.

## Run it

```sh
python3 main.py
```
